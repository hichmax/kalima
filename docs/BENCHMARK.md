# Benchmark ergonomique

Consulté le 25 juillet 2026. Aucun écran, identité, illustration ou texte n’a été
copié. Seuls les principes ci-dessous ont été retenus.

## Quran.com

- URL : https://quran.com/en
- Mise à jour mot par mot :
  https://quran.com/ar/product-updates/updated-word-by-word-recitation-feature
- Observation : lecture, récitation, traduction et étude sont accessibles depuis
  le même contexte ; l’audio mot à mot aide la prononciation.
- Application dans Kalima : contexte du verset toujours visible et audio prévu au
  niveau du verset/mot.
- Différence assumée : dans Kalima, les mots sont volontairement inertes en lecture
  normale et interactifs seulement après l’entrée explicite en mode étude.

## Tarteel

- URL : https://tarteel.ai/
- Aide : https://support.tarteel.ai/en/collections/15105266-tarteel-features
- Observation : masquage des versets, objectifs, modes lecture/écoute et suivi
  de mémorisation forment un parcours cohérent.
- Application dans Kalima : masquage progressif, premier mot comme indice,
  répétitions réglables et distinction claire entre mémorisation et lecture.
- Garde-fou : l’analyse de récitation future est présentée comme approximation.

## Duolingo

- URL : https://www.duolingo.com/learn
- Guide produit :
  https://blog.duolingo.com/duolingo-101-how-to-learn-a-language-on-duolingo/
- Observation : leçons courtes, difficulté progressive, retour immédiat et
  pratique ciblée réduisent la charge de décision.
- Application dans Kalima : durées 5–30 minutes, une notion à la fois, exercice
  immédiat, progression de reconnaissance vers production.
- Différence assumée : pas de série punitive, classement ou compétition.

## Anki / FSRS

- Manuel : https://docs.ankiweb.net/background.html
- Implémentation : https://github.com/open-spaced-repetition/ts-fsrs
- Observation : FSRS espace les rappels selon la difficulté et l’historique.
- Application dans Kalima : quatre réponses simples et états distincts par
  compétence ; interface centrée sur une seule carte.

## Interfaces de bien-être

Le brief demandait une qualité cocooning sans identité copiée. Les principes
retenus sont transversaux : largeur de lecture limitée, contraste chaud, espace
généreux, mouvement lent, absence de gamification anxiogène et actions
principales faciles à atteindre sur mobile.
